# 🍇 FRUDIA 炫酷互动抽奖页面

这是一个基于 Web 技术（HTML5/Canvas/CSS3）开发的互动抽奖演示项目，专为 FRUDIA 蜜罐产品设计。包含三个视觉冲击力强、交互有趣的“必中”抽奖方案。

## 🎮 包含方案

### 1. 🔮 命运炼金术 (Destiny Alchemy) - **推荐**
- **文件**: `tarot.html`
- **体验**: 神秘、优雅、仪式感。
- **玩法**: 屏幕悬浮 5 张神秘卡牌，用户需要依次翻开三张牌。
- **流程**: 
    1. 获得“蓝莓之魂”。
    2. 获得“黄金蜂浆”。
    3. 两种能量汇聚，炸裂合成最终大奖 FRUDIA 蜜罐。
- **特效**: CSS 3D 翻转 + 粒子爆炸 + 高级 SVG 质感渲染。

### 2. 🎨 甜蜜涂鸦 (Sweet Graffiti) - **NEW**
- **文件**: `graffiti.html`
- **体验**: 动手、解压、满足感。
- **玩法**: 屏幕变暗，用户手指/鼠标化身为画笔，在墙上涂抹金黄色的蜂蜜颜料。
- **必中逻辑**: 当涂抹面积达到一定比例，整个屏幕瞬间被蜂蜜填满，FRUDIA 蜜罐破壁而出。

### 3. 💥 果酱爆破 (Jam Blast)
- **文件**: `blast.html`
- **体验**: 爽快、解压、惊喜。
- **玩法**: 屏幕上漂浮着无数果酱球，点击可将其捏爆（物理破碎特效）。
- **必中逻辑**: 只要用户点击互动达到 5 次，或者点击特定区域，就会触发全屏“爆浆”特效。

## 🚀 如何使用

### 本地预览
1. 直接双击根目录下的 `index.html` 即可进入导航页。
2. 或者使用 VS Code 的 "Live Server" 插件打开。

### 部署到 GitHub Pages
本项目包含自动化部署脚本，可一键发布到 GitHub 供他人访问。

1. 运行 `github-manager.bat`。
2. 选择 `[1] 初始化与配置`（首次使用时）。
3. 选择 `[2] 一键部署`。
4. 部署完成后，访问 `https://<你的用户名>.github.io/gesture-particle-3d/` 即可。

## 🛠️ 技术细节
- **纯原生开发**: 无需 Node.js 依赖，无需 npm install，开箱即用。
- **Canvas 粒子**: 使用高性能 Canvas 2D API 渲染粒子爆炸效果。
- **CSS3 3D**: 利用 `transform-style: preserve-3d` 实现丝滑的卡牌翻转。
- **SVG 矢量图**: 手写 SVG 代码绘制 FRUDIA 蜜罐，模拟高级光影质感，无需外部图片。
